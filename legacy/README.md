# Aplikasi lama (Express + EJS)

Versi awal SIAKAD sebelum ditulis ulang menjadi `backend/` (TypeScript + Prisma) dan `frontend/` (React).
Disimpan hanya sebagai referensi; **tidak dipelihara** dan tidak dijalankan oleh CI.

- Memakai database `db_akademik` (terpisah dari `db_akademik_v2` milik backend baru).
- Menjalankan: `cd legacy && npm install && npm start`.
